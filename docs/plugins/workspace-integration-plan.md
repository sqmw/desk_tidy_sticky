# 插件与课表主窗口接入方案

执行阶段更新：用户已于本方案整理后明确要求「按照方案开始落地」，E-003实施及证据见[实施记录](workspace-integration-implementation.md)。下文保留方案制定时的目标与授权上下文；“仅文档/待实现”描述的是E-002当时状态，不覆盖当前STEPS记录。

版本：v1 · 2026-09-11。依据：D-EXT-007；归属：T-PLUGIN-HOST@v1。本文定义下一批产品行为，不是已实现证明；本轮授权仅为方案整理，代码实施另行启动。

## 1. 目标与现状

目标：在 Mac 工作台内完成「插件管理 → 安装 → 打开课表 → 导入/查看」，像切换笔记、专注和回顾一样切换内容，不默认增加系统窗口。

当前实现（303a375）通过 `openPluginsWindow` 创建独立插件窗口；笔记/专注/回顾则使用工作台内容区。这是为避开笔记编辑卸载风险做的设计取舍，不是系统异常，但造成了导航语义和视觉体验不一致。

旧版源码、安装/保存/重开证据及恢复说明保留于[Mac首版记录](mac-product-flow.md)。旧证据不能替代同窗口切换后的草稿、焦点、布局与生命周期回归。

## 2. 调研依据与本项目取舍

| 产品 | 官方说明中的做法 | 本项目采用的原则 |
| --- | --- | --- |
| VS Code | 扩展可进入当前工作台的侧栏、编辑区或面板；扩展管理有专门入口 | 功能扩展融入主窗口，而非默认打开另一个应用式窗口 |
| Obsidian | 设置中的社区插件页面负责安装、启停及配置 | 插件管理与插件业务分开，不把安装表单塞进课表 |
| Joplin | 配置中的插件页面管理插件；功能按插件自身设计集成进应用 | 管理入口统一，业务入口按实际使用场景安排 |

来源（2026-09-11核对）：[VS Code 工作台扩展 UX](https://code.visualstudio.com/api/ux-guidelines/overview)、[VS Code 扩展管理](https://code.visualstudio.com/docs/configure/extensions/extensions)、[Obsidian 社区插件](https://obsidian.md/help/community-plugins)、[Joplin 插件](https://joplinapp.org/help/apps/plugins/)。这些资料证明可采用的产品模式，不证明本项目已经具备相同运行隔离能力，也不代表所有插件都不能弹窗。

取舍：沿用已确认的侧栏「插件」，不再迁到设置深处；它打开主内容区的管理页。「课表」是安装启用后的业务快捷入口，打开同一内容区的课表页。当前不新增编辑器标签系统、可拖拽面板或通用扩展布局框架。

## 3. 页面位置与交互

| 操作 | 目标位置/行为 | 边界 |
| --- | --- | --- |
| 点击侧栏「插件」 | 工作台右侧插件管理页，侧栏对应项高亮 | 不调用新建窗口；不显示第二套品牌栏/重复导航 |
| 安装并启用课表插件 | 管理页显示成功，侧栏新增「课表」 | 必须经原生预检与权限确认；不自动切走当前页面 |
| 点击「课表」或管理页「打开课表」 | 同一工作台内容区显示课表 | 未安装/停用时不能进入；失效快捷入口回到管理页并说明原因 |
| 导入课表 | 课表页内选择文件、完整预览、确认保存 | 坏输入与取消不覆盖旧课表；高级 JSON 编辑保留 |
| 权限/停用/卸载确认 | 当前窗口内的小型对话框 | 说明数据与提醒影响；支持取消、焦点圈定及关闭后焦点恢复 |
| 停用/卸载 | 原生成功后刷新管理状态和侧栏 | 失败保留旧状态及错误；停用不是关闭页面，卸载仍保留数据 |

布局复用工作台内容容器、间距、字体、主题与滚动约定；不把独立页面的 `100dvh` 外壳直接嵌入内容区造成双滚动。亮/暗主题、窄窗口、侧栏折叠均须可用。文件选择器和系统权限提示仍可使用操作系统界面，它们不是本方案禁止的额外业务窗口。

## 4. 草稿与离开规则

页面位置与草稿生命周期分开设计；不能把「同窗口接入」简化为卸载旧页、挂载新页。

- 笔记 → 插件/课表：保留快速输入内容、当前笔记身份、未保存编辑稿和返回位置；返回后恢复相同笔记与草稿。正常保留状态的导航不反复弹确认，也不静默保存或丢弃用户输入。
- 若焦点移出触发了已有自动保存：等待结果；保存失败/冲突时停留原页，保留草稿与重试入口。导航动作不能先关闭编辑器再检查结果。
- 课表 → 其他内容页：保留当前查看日期/位置；存在未确认导入时先提示「继续导入」或「放弃导入并离开」，只有明确放弃才清除候选。普通已保存课表切换不弹确认。
- 安装、保存、停用、卸载正在执行时阻止重复提交和会卸载操作状态的切换，给出可见的处理中反馈；失败不提交目标导航状态。
- 任何真正丢弃草稿/关闭编辑会话的操作仍经过离开确认；窗口关闭与隐藏不能因本次接入绕过既有保护。隐藏工作台不同于退出应用；本批不承诺未保存草稿在进程退出后恢复。
- 隐藏的笔记/插件面板不能继续接收当前页面的快捷键、键盘焦点或滚动；保留状态不等于允许隐藏视图继续交互。

实施前需重点核对：`workspace/+page.svelte` 的 `setMainTab` 当前在离开笔记时直接调用 `closeInspector()`；`WorkspaceNotesPane` 是条件挂载。仅扩展 tab 枚举仍会关闭编辑器，不能作为草稿保护已完成的依据。

## 5. 最小改造与代码导航

| 模块 | 计划调整 | 保持不变 |
| --- | --- | --- |
| `src/lib/workspace/workspace-tabs.js` | 添加插件管理/课表导航语义，规范化失效或停用后的恢复值 | 笔记既有筛选语义；不借此建设通用插件路由注册框架 |
| `src/routes/workspace/+page.svelte` | 接入工作台插件面板与统一导航守卫；协调笔记状态保留 | 页面只装配，不堆安装/课表业务逻辑 |
| `src/lib/plugins/WorkspacePluginLinks.svelte` / `WorkspaceSidebar.svelte` | 从开窗口改为工作台导航回调，复用高亮/折叠/键盘样式 | 安装状态以原生响应为准，事件仅作刷新提示 |
| `src/lib/plugins/PluginManager.svelte` | 放入内容区，安装/生命周期确认改为窗内对话框 | 包选择、权限内容、成功/错误和数据处置合同 |
| `src/lib/plugins/TimetablePage.svelte` / `TimetableImport.svelte` | 适配内容区与导航守卫，保留查看上下文 | 外部 JS 解析、预览/确认保存、每日课程与错误反馈 |
| `src/routes/plugins/+page.svelte` / `open-window.js` | 不再作为桌面侧栏默认链路；复用可抽取的页面装配逻辑 | 旧路由和已有窗口暂留兼容，不强关用户窗口，不顺手删除移动入口 |
| `src/lib/plugins/product.css` | 将独立页壳样式与可嵌入面板样式分开，接入工作台主题 | 样式局部作用域，不污染笔记/专注/回顾 |

可按需要新增一个小型工作台插件面板与导航控制模块；不原样嵌套整个独立页面。优先复用现有状态持有者/编辑器，不新增第二份长期业务主数据。主窗口「workspace」已经在原生插件命令允许来源中，实施时核对实际接线，不以本方案新增窗口权限。

Worker、宿主权限、包摘要白名单、插件独立存储和通知接口均保留。业务面板隐藏/重开时只能有一个有效运行实例；停用/卸载必须释放运行实例和拒绝后续操作。将视图放入主窗口不等于把外部 JS 放进特权主页面执行，不能移除 Worker 或绕过 Rust 校验。

## 6. 拟实施顺序与验收

以下为获准开始代码实施后的顺序；本轮只交付方案。任务/阶段真实状态只在[TODO](../TODO.md#t-plugin-host)和[STEPS](../STEPS.md#t-plugin-host)维护。

1. **导航与草稿保护**：针对直接关闭编辑器和条件卸载风险，先明确保存中/失败/脏草稿导航合同并补反向测试；通过后再接入新页面，避免先交付会丢状态的导航。
2. **嵌入管理与课表**：复用现有组件接入内容区，修改侧栏跳转，补主题/滚动/对话框；做到从两个入口访问同一课表，不增加窗口或重复 Worker。
3. **Mac完整回归与收口**：隔离开发数据下验证下表；review、文档回写和小步提交。没有通过同窗回归，不沿用旧独立窗口实测宣称完成。

| 场景 | 通过标准 | 典型失败 |
| --- | --- | --- |
| 连续点击插件/课表、切回笔记 | 窗口数量不增加，高亮与内容一致 | 新窗口、重复标题栏或菜单选中错误 |
| 笔记输入/编辑中切到课表再返回 | 同一笔记、草稿及位置保持 | 草稿清空、跳到其他笔记或意外保存 |
| 自动保存失败/并发修改时导航 | 不离开、不覆盖，错误及重试可见 | 先卸载编辑器再提示失败 |
| 导入预览中离开 | 继续保留候选，明确放弃才清理 | 点击侧栏直接丢预览或偷偷保存 |
| 安装→导入→保存→进程重开 | 同一产品中可操作、已保存课程保留 | 只在测试替身下成功或重开数据为空 |
| 停用/卸载及旧入口 | 侧栏同步、Worker释放、旧操作被拒、数据保留 | 隐藏入口但旧实例仍执行或数据被删除 |
| 快速切换/失败重试/重复打开 | 单实例、无重复保存/提醒计划提交 | 重复监听、后台面板截获快捷键 |
| 亮暗主题/缩窄/侧栏折叠/键盘操作 | 内容可读、单一主滚动、确认框焦点正确 | 白色大块、操作被遮挡或焦点逃到隐藏视图 |

验证入口：`pnpm check`、`pnpm test:frontend`、`pnpm test:plugins:browser`、Mac原生冒烟及`git diff --check`。现有浏览器回归须扩展为真实工作台导航；模拟原生接口只证明交互，不替代 Mac IPC/持久化证据。没有 Rust 改动时不为流程数字重复编译全部原生测试；若接线改变原生行为，补相应测试。

## 7. 范围、风险与恢复

- 只先做Mac产品体验，不扩移动适配、插件商店、学校格式转换、自动同步或通知调度体系。课表 JSON v1和任意第三方安全门继续按原合同执行。
- 主要风险是草稿丢失、隐藏页仍接收事件、样式污染、重复Worker/命令，以及旧路由仍作为默认入口；以第6节的反例门禁控制，不靠另开窗口掩盖。
- 同窗管理和独立代码运行不冲突；任何安全边界变化均超出本方案。完整第三方安全、提醒长期计划与移动验收仍归原Tasks，不因UI方案通过而关闭。
- 无存储格式/用户数据迁移。实现按导航保护、页面接入和回归分可逆提交；回退先保留草稿和数据，经授权反向应用相关代码提交，不恢复或覆盖用户数据快照。
- 既有未提交原生适配、隔离配置、Android修正及运行进程原样保留。独立窗口以后若有「课表常驻桌面」需求再讨论为显式可选能力，非当前阻塞项，不在本批实现。
