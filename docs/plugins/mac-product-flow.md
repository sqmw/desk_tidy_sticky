# Mac 插件入口与课表使用流程

依据：D-EXT-006；Task：T-PLUGIN-HOST@v1 / S2。当前只在 Mac 实现与验证，不以移动端或通知适配扩建作为前置。

## 产品合同

- 工作台侧栏「插件」进入管理页；安装并启用后出现「课表」快捷入口。使用独立插件窗口，不切走未保存笔记。
- 管理页只负责本地 .dtplugin 包、预检、权限确认、打开、启停、卸载与错误反馈；不放课程编辑器。
- 课表页只在安装且启用后可使用；提供导入文件、格式说明、预览确认、保存、日期选课和课程展示。JSON 编辑属于展开后的高级入口，不占据默认主界面。
- 导入候选与已保存课表分离；取消候选或导入错误不改变已保存课程。预览显示全部课程及学期/节次/周次，避免导入非今天的课表却只看到空白。保存成功才替换，失败保留候选与原因。
- v0.1 明确支持 Desk Tidy JSON v1；「各种课表」通过课表插件逐个新增格式转换，不冒充任意学校文件兼容。本批保留官方包字节白名单，不降低第三方代码安全门。
- 提醒设置/已有提醒状态留在课表页，继续使用现有接口；不在本批实现新的系统调度方式。

## 实现导航

- `src/routes/plugins/+page.svelte`：页面容器与管理/课表导航。
- `src/lib/plugins/PluginManager.svelte`：安装与生命周期。
- `src/lib/plugins/TimetablePage.svelte`：已保存课表、导入候选、保存反馈。
- `src/lib/plugins/TimetableImport.svelte`：文件/高级 JSON 输入和全部课程预览。
- `src/lib/plugins/WorkspacePluginLinks.svelte`：工作台入口与安装状态刷新。
- `src/lib/plugins/open-window.js`：复用同一个窗口，指定管理或课表页面。
- 原生包校验/持久化、外部 JS 规则/Worker 沿用[产品基线](timetable-v01.md)，不迁移用户数据。

## 验证与恢复

检查入口显隐、权限确认、坏包拒绝、预览不覆盖、取消导入、保存后重开、停用/卸载保留数据及错误可见。浏览器 UI 自动化使用真实 Worker 和模拟原生接口，只证明交互；Mac 原生证据单独记录，不能互相替代。

既有未提交原生通知适配、开发隔离配置及 Android 修正原样保留，不混入本批前端提交。已有页面逻辑按职责迁入组件，保留提醒说明和调用。回退仅反向应用本批提交，无存储格式变化。
