# 2026-04-15 贴纸工具栏双排化与中心数值反馈

## 背景
- 单排工具栏在窄贴纸宽度下容易挤压，导致底部操作按钮显示不完整。
- `编辑` 按钮使用文字会额外占宽，与图标按钮混排时更容易破坏整体节奏。
- 透明度 / 磨砂在滚轮调整时，数值反馈贴在按钮附近，视觉中心偏下且偏右，不够稳定。

## 本次收敛
1. 工具栏改为响应式居中布局
- 宽度足够时，所有操作按钮在底部一排完整居中显示。
- 宽度不足时，按钮自动换行为两排，仍保持整体居中。
- 不再保留独立拖动带占位；拖动依赖工具栏容器的留白区域（按钮间隙与 padding），避免浪费垂直空间。

2. 编辑按钮改为纯图标
- 预览态显示铅笔。
- 编辑态显示确认勾。
- 语义仍通过 `title` 与现有行为保持一致，不再额外占用横向空间。

3. 滚轮数值反馈移到贴纸中心
- 透明度 / 磨砂滚轮调整时，不再在按钮附近显示小数值块。
- 当前值统一在贴纸中心以 HUD 形式短暂显示，保持视觉重心稳定。
- 滚轮调整时不再自动弹出滑杆面板，避免“按钮正下方挂着一条进度条”的视觉错位。

## 设计约束
- 保持贴纸底部 hover toolbar 的现有交互方式，不引入新入口。
- 不改变透明度 / 磨砂的数据结构与保存链路，只调整视觉反馈位置。
- 不改变颜色面板、文字色面板的点击外部收起规则。

## 回归点
1. 宽贴纸下工具栏保持单排居中；窄贴纸下自动换成两排。
2. 编辑按钮不再以文字形式占宽。
3. 滚轮调整透明度 / 磨砂时，仅显示贴纸中心 HUD，不再自动弹出滑杆。
4. 点击透明度 / 磨砂按钮后，滑杆面板仍能正常展开。
