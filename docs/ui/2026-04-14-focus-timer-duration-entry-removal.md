# 2026-04-14 番茄钟卡片时长入口移除

## 背景

番茄钟卡片右侧曾保留“单个番茄时长（分钟）”调节入口，但当前工作流里该入口既不属于任务级配置，也不承担明确的全局设置职责，容易让界面继续显得配置边界混乱。

## 本轮调整

1. 从番茄钟卡片中移除“单个番茄时长（分钟）”输入控件。
2. 保留番茄钟卡片的核心信息：
   - 当前任务
   - 当前计时
   - 今日番茄数
3. 清理对应的视图层参数透传，避免保留无效 UI 接口。
4. 将“单个番茄时长（分钟）”作为全局设置，放入工作台设置弹窗的 `Pomodoro` 区块中，并增加 `?` 提示说明生效规则。

## 结果

番茄钟卡片现在只承担展示与切换番茄/休息视图，不再额外挂一个没有明确产品定位的时长调节入口；时长配置被收敛到设置里，职责边界更清晰。

生效规则：

- 修改“单个番茄时长”只影响后续新的番茄周期，不回溯修改正在进行/已暂停的当前周期（倒计时与进度保持稳定）。

## 验证关注点

1. 番茄钟卡片在 focus 视图下仍能正常显示任务与今日番茄数。
2. 番茄 / 休息控制切换不受影响。
3. 删除时长入口后，布局没有出现空洞或错位。
4. 在计时进行中修改“单个番茄时长”：
   - 当前倒计时不应重置。
   - 当前进度条不应跳变。
   - 下一轮番茄应按新时长开始计时并计数。
