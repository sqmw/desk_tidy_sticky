# 2026-04-14 番茄钟摘要卡改为全局今日番茄数

## 背景

番茄钟卡片右侧原先展示的数值实际来自当前选中任务的 `taskPomodoros[selectedTaskId]`，但文案写的是“今日番茄数”，容易让人误解为当天全局总番茄数。

## 本轮调整

1. 顶部番茄钟卡片右侧改为显示当天全局番茄总数。
2. 数据来源切换为 `todayStats.pomodoros`。
3. 任务列表仍保留每个任务自己的 `🍅 xN`，用于明细统计。
4. 在“今日番茄总数”旁增加 `?` 提示，明确说明统计口径为“全局总数”，单任务明细在列表中查看。

## 结果边界

- 顶部番茄钟卡片：全局今日摘要
- 任务列表：单任务番茄明细
- “?”：在界面上可就地解释口径，避免用户需要去设置里猜测。

## 回归关注点

1. 未选择任务时，顶部右侧仍应显示当天总番茄数。
2. 完成一个番茄后，顶部总数和对应任务行的数值都应同步更新。
3. `?` 提示在番茄钟卡片 focus 视图下可见，hover 时能看到说明文案。
