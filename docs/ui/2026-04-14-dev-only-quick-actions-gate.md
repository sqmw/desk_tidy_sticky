# 2026-04-14 开发态快速测试入口门禁

## 背景

休息控制区域包含“快速测试 / 短休10秒 / 长休10秒”等开发辅助入口。这些入口仅用于本地回归与联调，不能进入发行版界面。

## 本轮调整

1. 新增统一开发态标记：
   - `src/lib/runtime/dev-flags.js`
   - `showDevQuickActions = Boolean(import.meta.env.DEV)`
2. `WorkspaceBreakControlBar.svelte` 中的快速测试入口改为仅在开发态渲染。
3. 发行版构建中，`import.meta.env.DEV` 为 `false`，因此该 UI 不会被渲染。

## 编码约定

后续如果再出现类似“仅用于本地调试 / 回归”的入口，统一按以下方式处理：

1. 不直接散落写在业务组件中。
2. 优先挂到统一的开发态标记模块。
3. 仅控制调试 UI 的显示，不污染正式业务逻辑。
4. 发行版默认不可见，不依赖人工记忆去删。

## 回归关注点

1. `pnpm run dev` 下应仍能看到快速测试入口。
2. 发行版构建产物中不应再显示快速测试入口。
3. 休息控制正常功能不受影响。
