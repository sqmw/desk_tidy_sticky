# Workspace 侧边栏「桌面贴纸 / 鼠标交互」开关改为 Toggle（2026-04-15）

## 判定
- 类型：UX 改进（不改变核心能力）

## 背景
- 侧边栏底部设置区原先使用按钮文案表达“关闭/切换”，在状态记忆与可视化上不够直观。
- 用户需要明确看到当前是否启用桌面贴纸、以及贴纸是否允许鼠标交互。

## 调整
- 位置：Workspace 左下角侧边栏设置区。
- 将两项入口从按钮改为 toggle 类型开关：
  - `桌面贴纸`：控制贴纸是否显示/关闭（对应 `overlayEnabled` / `stickiesVisible`）。
  - `鼠标交互`：控制贴纸是否可交互（关闭时为 click-through，不阻挡鼠标）。

## 回归关注点
1. 开关状态与实际行为一致：关闭贴纸时不应残留窗口；开启后能恢复展示。
2. 鼠标交互切换后，贴纸窗口应立刻响应（可点/不可点）。
3. 侧边栏折叠模式下仍可操作开关。
