# 2026-04-14 番茄任务提醒边界收口（Pass 2）

## 背景

番茄任务规划头部原先保留了一个独立的“编辑设置”入口，但该面板最终只剩任务开始提醒相关配置，导致任务规划、任务编辑和全局设置三者的边界不清晰。

## 本轮调整

1. 删除任务规划头部的“编辑设置”入口与展开面板。
2. 将“任务开始提醒”改为任务级配置，放入每个任务自己的“编辑”表单中。
3. 将“默认提前提醒（分钟）”收回到全局设置中统一维护，默认值仍为 `10` 分钟。
4. 任务开始提醒的运行时触发条件改为：
   - 任务本身开启了提醒
   - 当前已获得通知权限
   - 使用全局设置中的默认提前分钟数

## 结果边界

### 任务级

- `任务开始提醒` 开关
- 位置：任务卡片的 `编辑`

### 全局级

- `默认提前提醒（分钟）`
- 位置：工作台 `设置 -> General`

### 不再保留

- 任务规划头部的独立 `编辑设置`
- 任务规划区域中的提醒时间集中面板

## 回归关注点

1. 编辑任务时开启提醒，保存后再次进入编辑应能看到原状态。
2. 在设置里修改默认提前分钟数后，后续任务提醒应按新值触发。
3. 未开启任务提醒的任务不应再触发开始前提醒。
