# 课表周视图与视觉重设计

归属：T-TIMETABLE-PLUGIN@v1 / S2 / E-002。用户针对原每日大卡片截图明确要求重新设计；本批在已有工作台内重做课表展示，不扩建插件宿主、移动适配或提醒调度。

## 产品与视觉合同

- 周课表为默认主视图：七天横排、左侧节次与起止时间；周六日弱化，今天突出显示。去除宣传式副标题、“每日课程”重复标题和大块提醒卡片。
- 顶部紧凑显示课表/开学日期/总周数。上一周、下一周、周次选择及“回到本周”负责导航；日期统一中文月日，避免系统日期框的MM/DD歧义。
- 学期外仍展示最近的有效学期周，并明确“尚未开始/已结束”；不跳到不存在的第0周或超出总周数。正常切换工作台页面保留所选周。
- 课程用稳定的五组柔和色块区分；跨节课程跨行，名称/教室优先，时间可在跨行块及详情中查看。重叠课程并排，不互相遮盖；短名称和完整名称均保留可访问标签/详情入口。
- 导入为右上角次要操作；未导入时提供简洁空态和明确的首次导入按钮。导入仍先完整预览再确认，原有错误/取消/草稿保护不变。
- 课程详情和课表设置使用窗内对话框。提醒主界面仅显示“提前N分钟”入口；权限、范围及运行状态按需展开。旧“打开课表时重建计划”文案映射成实际的“需重新保存后更新”，不伪造自动调度已经发生。
- 色块、字体和网格继承工作台主题；可滚动区域可由键盘聚焦。最小网格宽620px，较窄窗口横向滚动，不把七天挤成不可读小字。节次数量决定网格高度，不虚构不存在的空节次。

## 实现与边界

| 源码 | 职责 |
| --- | --- |
| `src/lib/plugins/TimetablePage.svelte` | 课表页编排、周次状态、导入保存、按需设置 |
| `src/lib/plugins/timetable/WeekGrid.svelte` | 七天/节次网格、色块与课程详情；不执行课表业务规则 |
| `src/lib/plugins/timetable/week-layout.js` | 公历周导航、日期标签、稳定色号及已计算课程到网格行/并排通道的映射 |
| `src/lib/plugins/timetable/timetable-page.css` | 紧凑头部/导航、空态、页脚及设置样式；仅作用于课表，不改插件管理页 |
| `tests/frontend/timetable-week-layout.test.js` | 学期边界、跨年、单双周来源、跨节和冲突并排 |
| `scripts/tests/plugin-product-dom.mjs` | 原导入/导航安全回归加周次切换、无课周、课程详情、密集课表和主题对比度 |

周课程来自已有Worker的七次`view`调用，业务规则仍由经审查的外部插件代码执行。没有改动`entry.js`、插件包/摘要、JSON版本、原生接口或存储格式。网格只负责排列这些结果，不维护另一套单双周或课程推算真相。

## 验证与review

- 前端43项测试通过；Svelte检查0错误/0警告；生产前端构建通过。原插件安装、预览/取消/保存/重开、笔记导航失败保护和Worker回收的浏览器回归继续通过。
- 真实Svelte组件+实际Worker的浏览器测试新增：第一周课程详情、第二周无课、周次往返保留、10门/8节密集排版、亮暗和窄窗口截图。原生IPC仍是测试替身，本轮未把这些结果冒充新的Mac原生安装/通知验收。
- Review修正全局按钮样式覆盖课程色块的优先级问题，并加入多色断言；主题切换截图停用中间动画后检查，深色课程标题对比度至少4.5:1。混用系统日期和隐藏运行信息不再占据主视图。
- 较少课程使用原`example.json`；丰富课表仅为浏览器测试构造数据，不写用户应用数据，不进入插件包。截图与测试状态留系统临时目录，业务数据不落同步仓库。
- 原生未提交改动原样保留；本批只提交课表UI/测试/文档。既有运行应用、安装版和用户数据未替换。无存储迁移；经授权可反向应用本批提交恢复旧展示，已保存JSON无需回迁。
- 边界：仍仅支持课表JSON v1；提醒设置通过重新导入保存更新，不新增原生调度；学校格式转换、调停课编辑、移动平台和任意第三方安全门不在本次完成范围。
