# 2026-04-14 专注任务主按钮状态语义修正

## 背景

任务列表右侧主按钮原先主要依赖“当前是否为选中且已开始的任务”决定显示 `开始 / 暂停 / 继续`。这会导致已有进度但当前未处于激活态的任务仍然显示 `开始`，与用户对“继续任务”的直觉不一致。

## 本轮调整

1. `运行中`：显示 `暂停`
2. `已有进度但未运行`：显示 `继续`
3. `从未开始`：显示 `开始`

## 判定依据

任务已有进度的判断使用：
- `effectiveSeconds > 0`
- 或 `donePomodoros > 0`

## 结果

任务列表主按钮现在更符合用户心智：
- 正在做：暂停
- 做过但当前没跑：继续
- 还没做：开始
