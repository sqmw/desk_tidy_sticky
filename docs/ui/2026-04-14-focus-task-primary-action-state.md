# 2026-04-14 专注任务主按钮状态语义修正

## 背景

专注任务列表是串行模型：同一时间只能有一个任务处于执行链路中。因此任务右侧主按钮不能按“历史上是否做过”推导 `继续`，而必须只看当前激活任务的运行态。

## 正确语义

1. 当前激活任务正在运行：显示 `暂停`
2. 当前激活任务已开始但当前暂停：显示 `继续`
3. 其他所有任务：显示 `开始`

## 判定边界

按钮状态仅依赖当前任务运行态：
- `startedTask`
- `runningTask`

不再使用：
- `effectiveSeconds > 0`
- `donePomodoros > 0`

这些值只代表历史进度，不代表当前仍处于可继续的激活任务。

## 结果

主按钮现在符合串行任务模型：
- 开始后变暂停
- 暂停后变继续
- 非当前任务一律仍是开始
