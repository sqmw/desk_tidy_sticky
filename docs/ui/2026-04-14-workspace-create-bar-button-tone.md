# Workspace Create Bar 主按钮色调调整

日期：2026-04-14
状态：已完成

## S：背景

workspace 顶部创建栏里，“新建笔记”使用了较重的深蓝实底，而“写长文档”是浅色描边按钮。两者虽然形成主次，但主按钮的视觉重量偏大，容易压住同一组操作里的其他元素。

## T：任务

本轮目标是保留“新建笔记”作为主入口的强调关系，但把按钮色调调轻，让它更像同一组操作中的主按钮，而不是过重的独立色块。

## A：行动

- 更新 `src/lib/components/workspace/toolbar/WorkspaceCreateBar.svelte`
- 将 `primary-btn` 从深色实底改为轻量强调样式：
  - accent tint 边框
  - 浅色渐变底
  - 更深的 accent 文本色
  - 更轻的默认阴影
  - hover 时再提高一点强调强度

## R：结果

- “新建笔记”仍然保持主 CTA 身份。
- 与“写长文档”的主次关系仍在，但差距更克制。
- 整组按钮的视觉语言更统一，不会出现主按钮压住周围输入区和次按钮的情况。
