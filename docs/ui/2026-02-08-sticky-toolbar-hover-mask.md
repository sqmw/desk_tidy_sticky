# 2026-02-08 Sticky 底部工具栏悬浮遮罩交互

## 目标
默认显示更多正文内容；鼠标悬浮时再显示底部工具栏，并用遮罩降低底部文字干扰。

## 调整
- 文件：`src/routes/note/[id]/+page.svelte`
- 变更：
  1. 工具栏改为绝对定位覆盖层，不再占用正文布局高度。  
  2. 新增 `toolbar-mask`（底部渐变遮罩），仅在悬浮时显示，并提高遮挡强度。  
  3. 工具栏增加半透明底板、描边、阴影与轻微模糊，避免底层文字干扰图标可读性。  
  4. 悬浮时工具栏淡入并启用点击；非悬浮状态下工具栏隐藏且不接收指针事件。

## 结果
1. 非悬浮状态下底部区域可继续显示文本内容。  
2. 悬浮后底部文字会被明显遮挡，工具栏按钮不再受正文视觉干扰。

## 2026-04-16 补充：底部遮罩与贴纸圆角裁剪同步

### 背景
- 在贴纸开启透明 / 磨砂后，底部工具栏遮罩仍按矩形铺底。
- 悬浮或操控态下，左右下角会露出“方形透明块”，视觉上像贴纸圆角被切坏。
- 该问题在 macOS 与 Windows 都会出现，只是合成表现略有差异。

### 调整
1. `toolbar-mask` 不再从 `0/0/0` 直接铺满到底部，而是收紧到贴纸 client 区内侧。
2. `toolbar-mask` 的底部圆角改为跟随贴纸主半径，避免遮罩自身把底角切成方形。
3. 贴纸正文容器补齐 `border-radius + overflow: hidden`，确保底部遮罩、正文层与磨砂层走同一套裁剪边界。
4. 贴纸主壳增加窗口级 `clip-path` 圆角裁切，外阴影改为跟随形状的 `drop-shadow`，不再让矩形窗口壳残留在圆角外。

### 回归点
1. 悬浮显示工具栏时，左右下角不应再出现方形透明块。
2. 编辑态 / 操控态下，底部遮罩过渡仍应保留，但只能沿贴纸圆角收口。
3. macOS 与 Windows 下，贴纸边缘都不应再露出矩形合成边。
