# 番茄任务设置面板去耦与布局收紧

日期：2026-04-14
状态：已完成

## S：背景

在 workspace 的番茄任务规划区里，“编辑设置”展开后虽然挂在番茄任务规划下面，但文案仍然直接提到“休息控制”，同时面板视觉上过于松散，容易让用户误解这块仍然与休息控制耦合在一起。

## T：任务

本轮目标是把这块设置明确收口为“番茄任务设置”：

- 文案只描述番茄任务自身
- 不再在这个面板内强调休息控制
- 布局更紧凑，避免出现大面积空白展开区

## A：行动

- 更新 `src/lib/components/workspace/pomodoro/WorkspaceFocusSettingsPanel.svelte`
  - 增加面板标题
  - 将设置项改为紧凑的 row/card 布局
  - 调整栅格为双列紧凑编排
  - 保留保存 / 取消动作
- 更新 `src/lib/strings.js`
  - 新增 `pomodoroTaskSettingsTitle`
  - 将 `pomodoroTaskSettingsHint` 改为仅描述番茄任务本身

## R：结果

- “编辑设置”展开后现在更明确地表达为独立的番茄任务设置区。
- 番茄任务设置与休息控制的心智边界更清楚。
- 展开区域的视觉节奏更紧，不再像一大片松散空白区。
