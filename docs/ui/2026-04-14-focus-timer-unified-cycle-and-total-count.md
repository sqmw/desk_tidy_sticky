# 2026-04-14 番茄计时口径统一与总数展示修正

## 背景

现场问题包含三项：

1. 文案希望明确为“今日番茄总数”。
2. 顶部番茄计数看起来一直是 `0`。
3. 某些任务开始后，倒计时出现“重新计时”的体感。

根因是顶部显示口径混用：
- 倒计时/进度部分使用了任务目标周期（`task.targetSeconds`）
- 完成计数使用了番茄周期（`focusMinutes`）

导致视觉上先“归零重启”，但番茄完成结算并未触发，进而让总数看起来不增长。

## 本轮调整

1. 顶部倒计时统一改为番茄主计时 `remainingSec`。
2. 顶部进度条统一按番茄主周期计算，不再按任务目标周期计算。
3. `pomodoroTodayPomodoros` 文案更新为：
   - `Today total pomodoros`
   - `今日番茄总数`

## 结果

- 顶部显示口径统一为番茄主周期：
  - 不再出现任务目标周期触发的“提前归零重启”错觉。
- 番茄总数与完成结算口径一致：
  - 完成一个完整番茄周期后再累加。

## 回归关注点

1. 启动任务后，顶部倒计时应连续递减，不应在任务目标周期边界重置。
2. 完成一个完整番茄周期后，“今日番茄总数”应 +1。
3. 任务列表中的单任务 `🍅 xN` 与顶部总数保持可解释关系（总数是全局，任务行是明细）。
