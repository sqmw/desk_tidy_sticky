# 2026-06-29 Workstation UI Cleanup

## Situation

workstation 当前的主要问题不是功能不足，而是视觉层级和信息密度偏硬：侧边栏框感太强，主区域顶部占位偏重，卡片操作常驻导致浏览态噪音高。

本轮按用户明确方向重做，不碰右上角设置入口，不改便笺块编辑模型。

## Task

- 左下角保留两个高频开关，常驻可见。
- 侧边栏去掉多余框和内部小滚动感。
- 顶部创建和搜索尽量轻量化。
- 卡片操作默认隐藏，hover / focus 再出现。

## Action

- `WorkspaceSidebar.svelte`
  - 底部改回两个常驻按钮式开关。
  - 去掉“设置”折叠入口。
  - 弱化块边框和内部分割感。
  - 2026-07-01 修正：左侧栏取消可见内部滚动条，压缩侧栏 padding、分区间距和底部开关高度，让当前内容量在常规窗口内直接完整呈现。
  - 2026-07-01 修正：取消左侧栏内部手动高度拖拽，原拖拽短线改为纯视觉分隔线；上方分隔线和底部开关上方分隔线使用统一 inset、颜色和线宽。
  - 2026-07-02 修正：左侧栏中间内容区改为受约束的隐形滚动容器，底部两个高频开关继续贴底但不再遮挡专注页 deadline 列表尾部内容。
  - 2026-07-02 修正：左侧栏最小宽度与窄态表达继续收紧，窄到低宽度时自动减少标题、说明文案和按钮高度，避免“左侧”信息层级在极窄状态下显得拥挤凌乱。
  - 2026-07-02 修正：极窄宽度下不再沿用完整文字式栏目表达，主导航、视图筛选和底部开关改为更短的窄态排版，减少单字竖排和底部宽按钮造成的碎裂感。
