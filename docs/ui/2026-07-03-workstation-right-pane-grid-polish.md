# Workstation 右侧内容区网格与卡片边界优化

## Situation

当前 workstation 右侧内容区从早期“卡片壳过重”调整到“内容过轻”后，出现新的视觉问题：

1. 笔记内容边界过弱，像漂浮在背景上。
2. 网格间距与卡片边界不足，扫读时缺少稳定锚点。
3. 顶部创建与搜索区在部分宽度下显得同权、占位偏重。
4. 默认主题模板仍会把 `.card` / `.quadrant-note-card` 置为透明，导致主题重置后容易回退。

问题归类：设计回归，不是数据或功能 bug。

## Task

本轮目标不是恢复厚重传统卡片，而是建立“轻量内容单元”：

1. 右侧笔记有清晰边界，但不做重阴影、厚背景或大圆角。
2. 普通列表使用稳定 responsive grid，先不引入 Masonry。
3. 卡片内部维持固定 padding、顶部元信息、正文摘要、底部标签的层级。
4. 顶部操作区让快速创建保持主入口，搜索和标签筛选保持辅助入口。
5. 组件样式和默认主题模板同步，避免重置主题后视觉回退。

## Action

实施顺序：

1. `WorkbenchNoteGrid.svelte`
   - 普通笔记从透明内容块改为轻量卡片。
   - 使用统一列宽、gap、内边距、淡边框和轻背景。
   - 正文摘要保留 4 行截断，标签固定在底部。
   - 操作按钮继续 hover / focus 显示，避免浏览态噪音。
2. `WorkbenchQuadrantBoard.svelte`
   - 四象限内笔记卡片同步轻量边界，避免同一工作台内视觉语言不一致。
3. `WorkspaceToolbar.svelte`
   - 创建区为主列，搜索区为辅助列，减少两个输入框同等重量的感觉。
4. `theme-default-template-sections.js`
   - 默认主题模板同步卡片边界、按钮和标签样式。
5. `docs/TODO.md`
   - 更新主 TODO 的当前下一步和专题索引。

## Result

验收方式：

1. `make check`
2. `git diff --check`
3. 视觉确认：
   - 笔记不再漂浮。
   - 右侧网格间距统一。
   - 卡片边界清楚但不过重。
   - 顶部创建/搜索区主次更明确。
