# 贴纸标签栏展示态统一

## 判定

- 类型：设计策略收敛。
- 背景：当前贴纸在置顶展示态默认不显示标签栏，但贴在底部时只要存在标签或优先级，就会把标签栏显示出来，造成同一张贴纸在不同层级下呈现两套视觉规则。

## 决策

采用方案 A：

- 展示态：不显示标签栏。
- 编辑态：显示标签栏和标签编辑入口。
- 控制态：显示标签栏，便于操作。

也就是说，置顶 / 置底在日常展示态统一为“只看内容，不展示标签元数据”。

## 原因

1. 贴纸的核心是内容本身，不是元数据卡片。
2. 标签和优先级属于组织辅助信息，默认常驻会抢占正文空间。
3. 置顶 / 置底只应该影响层级，不应该改变标签栏展示规则。
4. 统一展示态和编辑态边界后，用户心智模型更稳定：
   - 看内容时干净
   - 改内容时显示结构化信息

## 实现

- `NoteTagBar` 的显示条件收敛为：
  - `isEditing`
  - `isControlMode`

不再因为“存在标签 / 存在优先级”就在展示态自动显示标签栏。

## 回归检查

1. 置顶贴纸展示态不显示标签栏。
2. 置底贴纸展示态也不显示标签栏。
3. 进入编辑态后，标签栏正常显示并可编辑。
4. 控制态下，标签栏正常显示，不影响已有操作入口。
