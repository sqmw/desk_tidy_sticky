# 贴纸工具栏移除“全局操作”入口

## 判定

- 这是设计收敛，不是功能缺失。
- “全局操作”属于全局态，不应在单个贴纸工具栏中重复出现。

## 问题

- 每个贴纸显示操作按钮时，工具栏里都出现“全局操作”按钮。
- 用户容易误以为这是“当前贴纸”的局部交互开关。
- 实际上该按钮切换的是所有贴纸共享的全局交互状态，作用域与按钮所在位置不一致。

## 调整

- 删除单贴纸 `NoteToolbar` 中的“全局操作”按钮。
- 删除单贴纸页面里已经不再需要的 `toggleGlobalControl()` 调用链。
- 保留真正的全局入口：
  - 左侧设置/侧栏中的全局交互开关
  - 托盘入口
  - 全局快捷键

## 影响文件

- `src/lib/components/note/NoteToolbar.svelte`
- `src/routes/note/[id]/+page.svelte`

## 回归要点

1. 打开任意贴纸进入操作态，确认工具栏里不再出现“全局操作”按钮。
2. 左侧全局交互开关仍然可用。
3. 托盘和全局快捷键仍然可切换贴纸全局交互状态。
