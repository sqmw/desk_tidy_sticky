# Workstation 四象限新建默认 Q2 修复（2026-04-16）

## 判定

Bug / 旧设计残留。

## 现象

在 workstation（工作台）左侧选择「四象限」视图后，右侧新建笔记区域的标签/优先级会自动选中 `Q2`。这会让用户以为只是切换了视图，实际新建表单已经被隐式写入四象限优先级。

## 根因

- `src/routes/workspace/+page.svelte` 中的视图联动逻辑在进入四象限时自动把 `newNotePriority` 写成 `2`。
- `src/lib/panel/use-note-commands.js` 的保存逻辑在四象限视图下会把空优先级兜底成 `2`。

## 修复

- 四象限视图不再自动选择 `Q2`。
- 保存新笔记时不再按视图隐式补齐 `Q2`。
- 离开四象限视图时仍清空新建优先级，避免用户手动选择的 `Q1~Q4` 污染普通视图的新建笔记。

## 影响

在四象限视图中，如果用户不手动选择 `Q1~Q4`，新建笔记会保持未标记状态，因此不会出现在四象限分组里。需要进入四象限的笔记应由用户显式选择优先级。
