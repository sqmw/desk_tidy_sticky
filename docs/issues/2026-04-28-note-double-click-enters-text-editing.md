# 贴纸双击直接进入正文编辑

## 背景

顶层贴纸当前支持双击进入“可操作状态”，但正文真正可编辑仍然需要用户再点击一次工具栏里的编辑按钮。

这会让用户对“编辑模式”的理解出现断层：

- 双击后视觉上已经进入编辑相关状态
- 但正文实际上还是只读预览
- 用户还要再执行一次“点笔按钮”的二级动作

对于“快速记录”的主场景来说，这一步是多余的。

## 根因

贴纸页把两种状态分开了：

- `isControlMode`：显示工具栏、标签等控制 UI
- `isEditing`：正文切换到 `SourceEditorPane` 并聚焦文本框

原来的双击只调用 `enterControlMode()`，不会进入 `enterEditMode()`，所以正文不会立即进入可编辑态。

代码路径：

- `src/routes/note/[id]/+page.svelte`
  - `handleNoteDoubleClick()`
  - `enterControlMode()`
  - `enterEditMode()`

## 方案

把双击语义直接收敛为“进入正文编辑态”：

- 双击顶层贴纸
- 直接调用 `enterEditMode()`
- `enterEditMode()` 内部继续复用现有逻辑：
  - 顶层贴纸自动拉起控制态
  - 正文切到编辑器
  - 光标自动聚焦到文本末尾

这样保持了现有工具栏和标签展示逻辑，同时去掉了多余的一次点击。

## 结果

修改后行为：

- 顶层贴纸双击后，正文立即可编辑
- 不再需要再点一次工具栏里的笔按钮
- 现有保存、退出、工具栏展开逻辑保持不变

## 回归关注点

重点关注：

1. 顶层贴纸双击后是否直接出现文本光标
2. 退出编辑后工具栏高度是否正常恢复
3. 非顶层贴纸双击行为是否未被误改
