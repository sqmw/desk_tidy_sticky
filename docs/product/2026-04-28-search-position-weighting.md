# 搜索排序收敛：按正文位置加权，而不是假设存在标题

## 结论

当前项目的笔记模型只有一份正文 `note.text`，没有独立标题字段。

因此搜索排序不应再按“标题优先”设计，而应按**同一份正文中的命中位置**进行加权：

- 正文开头/首行命中更靠前
- 正文前几行命中次之
- 正文深处命中仍可搜到，但排序靠后
- 标签命中可作为补充，但低于正文命中

## 本轮调整

### 1. 统一搜索语义

mini 和 workstation 统一使用同一套 `matchNote(...)` 评分规则：

- 搜正文
- 搜标签
- 支持中文拼音 / 首字母 fallback

### 2. 位置感知评分

搜索不再只做整篇文本的 `equals / startsWith / includes`，而是按正文区域分层：

1. 首行精确/前缀/包含
2. 前几行预览区域命中
3. 正文前段命中
4. 全文命中
5. 标签命中
6. 拼音全拼 / 首字母命中

这更符合“只有正文，没有独立标题”的产品模型。
